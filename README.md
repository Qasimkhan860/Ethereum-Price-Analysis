# 📈 Ethereum Price Analysis Dashboard

## 📌 Project Overview
Analyzed 5+ years (2017–2022) of historical Ethereum (ETH) data using SQL and Power BI to identify key price trends, yearly growth, and trading volatility.

## 🛠️ Tools & Technologies Used
- **SQL (MySQL):** Data extraction, filtering, and aggregation
- **Power BI:** Custom DAX measures, Data Modeling, and Dashboard Design
- **Excel:** Initial data exploration and preparation

## 📊 Key Business Insights
- **Yearly Growth:** Recorded a 9x average price surge in 2021 compared to previous years.
- **Volatility Trends:** Identified peak trading volume and periods with the highest daily price fluctuations.
- **Market Trends:** Highlighted correlation patterns between daily trading volumes and price spikes.
