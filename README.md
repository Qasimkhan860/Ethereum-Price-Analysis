# 📈 Ethereum Price Analysis Dashboard

## 📌 Project Overview
Analyzed 5+ years (2017–2022) of historical Ethereum (ETH) data using SQL, Power BI, and Excel to uncover long-term price performance, daily volatility, and YoY growth patterns.

## 🛠️ Tools & Technologies Used
- **SQL (MySQL):** Data extraction, filtering, and aggregation
- **Power BI:** Custom DAX measures, Data Modeling, and Dashboard Design
- **Excel:** Data exploration and initial validation

## 📊 Key Business Insights
- **All-Time High vs. Low:** Recorded an All-Time High closing price of **$4,812** against an All-Time Low of **$84**.
- **Massive YoY Growth (2021):** The year 2021 experienced an exceptional surge in growth compared to previous years, marking the most aggressive bull run in ETH history.
- **Yearly Average Performance:** 2021 and 2022 maintained the highest average closing prices (~$2.8K–$3K), significantly outperforming the 2017–2020 period.

### Key Dashboard Components:
* **KPI Cards:** Displays All-Time High/Low ($4,812 / $84) and Peak Day High/Low metrics ($4,892 / $83).
* **YoY Growth Bar Chart:** Highlights year-over-year percentage performance spikes across 2017–2022.
* **Trend Analysis Line Chart:** Tracks price trajectory across Years, Quarters, Months, and Days.
* **Granular Table View:** Enables detailed matrix drill-down into specific daily average prices.
